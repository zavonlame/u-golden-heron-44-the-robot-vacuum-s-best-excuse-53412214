One-line excuse a robot vacuum gives for missing a spot (140 characters or fewer), built for the [make.fun bounty](https://make.fun/c/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214).

> I mapped that corner as a wall. It has been a wall for three weeks. I do not argue with the map.

`main.ts` (Node 22, stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
